Chip-8 Interpreter / Emulator in python and pygame. 
Based on the excellent [guide](https://tobiasvl.github.io/blog/write-a-chip-8-emulator/) by [Tobias V. I. Langhoff](https://tobiasvl.github.io/) 

to use,  > pip install -r requirements.txt, then `python chip8py.py <your chip8 rom>.ch8`, replacing 
`<your chip8 rom>` with your chosen chip-8 rom. 

Keypad follows normal Chip-8 emulator conventions, 

**1 2 3 4
q w e r
a s d f
z x c v**
